# V0.3 limitations

This is a release-gated implementation. A green core suite alone is not final acceptance.

* No official Xanathar/Tasha pack is publicly distributed; private OCR inventories are preparation, not rule validation.
* No Kobold traits are inferred or invented. An unavailable origin is a custom origin requiring explicit GM review.
* Full historical level-by-level legality requires advancement snapshots; a high-level current sheet alone cannot establish acquisition history.
* Manual/partial abilities remain labelled; local preview requires explicit adjudication. It does not implement Encounter, RPG Connect, FX or the V0.4 dashboard.
* Browser emulation is not a physical iPad/Safari test. Final report must distinguish these.
* Private data remain on this browser/device; no account or cloud backup is provided. Export is the user-controlled backup.

The origin/background step is currently a declared custom path with final ability scores and GM review, rather than a complete racial/background catalogue. Historical snapshots have compiler support but are not graphically authored by this release candidate. Equipment selection currently covers armor/shield profiles; a comprehensive starting-equipment and weapon picker is not included. A prior permanent choice is retained when a class/level changes and may need explicit removal after review.
