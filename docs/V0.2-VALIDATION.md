# Validation V0.2

La PR #1 est fusionnée ; V0.1 est conservée sans modification de src/model.js, src/engine.js, src/storage.js ou src/connect.js. Les nouvelles suites s'exécutent avec les suites V0.1.

Commandes reproductibles :

```sh
npm ci --ignore-scripts
npm test
npm run demo
npm run demo:characters
```

CI : matrice Node 22 et 24, dépendances de test verrouillées. Tests unitaires, fixtures de six classes, schémas Ajv, migrations, bibliothèque, deux adaptateurs de stockage, corruption et interruptions injectées.

Résultat intermédiaire confirmé : **95 tests réussis**, Node 22 et 24, démos réussies, sur commit fc733e87f9024e32b4d7f772891265e8d45b1eb2 :
https://github.com/bryantoualy-del/Pilot20/actions/runs/38817341117

Les ajouts ultérieurs (prérequis de scores et documentation) doivent également passer avant livraison. Le résultat final est inscrit dans la PR.

La démonstration exécute un guerrier et un ensorceleur synthétiques. Les six classes utilisent le même modèle et le même moteur, sans logique liée à leur identité.

Limites : IndexedDB émulé, quota et interruption simulés, pas de validation Safari/iPad, pas de charge longue mesurée sur appareil, pas de déploiement ni de test réseau Encounter. Les états, effets temporaires et automatisations conditionnelles restent représentés ou reportés selon V0.2.md.
