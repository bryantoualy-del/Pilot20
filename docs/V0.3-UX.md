# V0.3 UX

One creation plan survives mode changes. Quick mode offers explicit user-triggered template suggestions; guided mode exposes adaptive steps; expert mode additionally exposes multiclass controls. No mode silently finalizes a suggestion. Required choices always retain count/selection state.

Origin is an explicitly declared custom origin: no absent racial traits are fabricated. Final ability scores, languages, traits and two background skills are entered graphically. Equipment profiles feed the character contract and derive. These declarations require GM review. This implementation does not claim a complete SRD ancestry catalogue.

Choices come from resolveProgression; subclass steps appear only when the class unlocks them. Spellbook, preparation and Magical Secrets remain separate choices. Each option has its catalogue name and inspection; large lists have search and a bounded scrolling region. When levels/classes change, obsolete decisions remain until reviewed and explicitly removed.

All view strings are centralized FR/EN. Private entry names use pack translations; protected descriptions are not copied. Missing translations fall back to the verified English catalogue name. Touch targets are at least 44 px, keyboard focus is visible and no action depends on hover. Responsive layouts target 1180×820, desktop and 390 px phones.

The final lot adds a visible Versatile / Support / Offensive model selector. Suggestions prioritize a short original list of useful eligible skills/spells, then fall back to the installed choice pool; legality still comes solely from the resolver. Quick-mode Continue uses the shortened identity → class → level → origin → background → summary path, while every detailed step remains accessible. Unresolved mandatory choices block finalization.
