## Validation possible sans inventer ces données

Les tests utilisent des personnages **synthétiques** pour les six familles classe/sous-classe et pour les versions raciales disponibles. Ils vérifient acquisition de capacités, ressources, règles dérivées et routes de sorts. Cela ne valide ni les PV, ni la CA, ni l’inventaire final de ces six fiches réelles. Aucune fiche réelle n’a été modifiée, importée par approximation ou déclarée reconstruite.

Les différences de campagne relevées ne bloquent pas le test des règles standard ni la préparation du candidat. Elles exigent une décision ciblée seulement si l’objectif devient la reproduction exacte de ces fiches dans le Créateur. Les interfaces Companion/RPG Connect existantes restent conservées ; leur moteur de combat n’est pas étendu ici.
