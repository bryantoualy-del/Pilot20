# P29 — Options Tasha et voies d’invocation (2014)

Critères : options désactivées par défaut ; acquisition automatique après activation et niveau requis ; un seul remplacement partagé aux ASI concernées ; aucune reconstitution des anciens niveaux. Formules de sort mineur propose un échange explicite après repos long dans le Grimoire avec journal daté. Fin explorateur remplace les terrains et applique réellement les vitesses. Les invocations SRD qui accordent un sort créent une origine distincte au Grimoire ; les restrictions de cible et les doubles coûts restent explicitement manuels, sans moteur de combat ajouté.

Validation : tests dédiés Tasha, dons et réédition ; CI complète de la pile sur le commit de la PR. Les résumés français sont originaux, références Tasha/SRD distinctes. Vérification physique Safari à réaliser sur appareils.
