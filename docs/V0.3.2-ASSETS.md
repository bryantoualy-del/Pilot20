# V0.3.2 — Assets

Source : [RPG Connect](https://github.com/bryantoualy-del/RPG-Connect), révision `204f044860ef18ef6268494236a682fa201c5202`. Inspection du README, de `rpg-connect-icon-registry.js`, de `rpg-icons.js`, des shards `assets/icon-data/` et des dossiers `assets/icons/`.

Le propriétaire confirme dans la mission du 17 octobre 2026 avoir généré les images concernées avec ChatGPT et autorise leur réutilisation dans Pilot20. Cette autorisation est le fondement de la copie ; aucune licence générale du code RPG Connect n'est inventée.

67 WebP optimisés existants, extraits sans modification des data URI : 13 classes, 8 écoles, 31 inventaire, 15 états ; **166 648 octets** au total. Images 64×64, destinées aux icônes et cartes compactes, pas à de grandes illustrations. Pas de réencodage destructif. Les créatures et variantes boss ne sont pas reprises : elles ne sont pas nécessaires au créateur et leur provenance n'est pas présumée.

Le manifeste `web/assets/shared/manifest.json` donne pour chaque fichier : clé normalisée, chemin local, fichier source, taille et SHA-256. Il contient la révision source et l'autorisation. Aucun PDF, illustration officielle, modèle PDF, police ou donnée de règles protégée n'est importé.

`assetURL(type,id)` fournit une URL locale stable ; `assetImage` crée une image décorative à chargement différé avec dimensions réservées et fallback sur erreur. Clés `class/fighter`, `class/bard`, `school/evocation`, `inventory/generic_sword`, `condition/...`. Les applications peuvent embarquer ce registre et ce dossier indépendamment ; aucune API réseau commune imposée. L'intégration des deux autres applications est hors périmètre de cette PR.

Usage : cartes de classe, aperçu de personnage, écoles dans le détail des sorts. Les autres familles sont disponibles pour des usages ciblés. Les sous-classes sans image dédiée utilisent le vocabulaire de leur classe et ne reçoivent pas de fausse illustration officielle.

Le packaging inclut les WebP locaux et le manifeste dans le cache versionné. Le service worker précache ces petites ressources pour assurer le hors ligne ; le décodage/affichage reste différé avec `loading=lazy` et `decoding=async`. Aucun téléchargement GitHub Raw à l'exécution. Le budget total de ce sous-ensemble rend un précache prévisible préférable à une installation incomplète des icônes.
