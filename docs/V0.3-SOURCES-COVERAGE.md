# Sources and coverage

SRD 5.1 is the public installed catalogue: 12 classes, their SRD subclass, 319 spells, features and choices. Automation is entry-specific and most complex rules still need adjudication. Consult runtime counts rather than treating a selected source as complete.

Xanathar and Tasha are selected by default but ship with **zero protected definitions**. The two supplied French PDFs were opened locally. A separate private inventory records chapter-1 subclasses, spell candidates, optional rules and page references. OCR candidates and unresolved mechanics are marked unverified. English correspondences are not asserted from the French text alone.

Original fixtures test extension contracts, not official Glamour, Eloquence or Artificer rules. Public documentation deliberately contains no extracted descriptions or private pack. Actual authorized JSON packs use `pilot20-private-rule-pack` schema 1 containing catalogue v3. Install is local, transactional and inert; handlers are whitelisted, never evaluated.

An installed class may declare half progression, preparation, level-1 spellcasting and ceil multiclass contribution. Subclasses and optional features may provide grants, resources and choices. `campaignOption` keeps each optional rule separate. Background/origin customization requiring unavailable rules stays explicitly manual; no racial traits are inferred from a name.

Release distinction: source selected ≠ installed data ≠ automated mechanics ≠ validated official rules. A missing extension does not erase stored plans. Re-enable/install it and run complete validation again.
