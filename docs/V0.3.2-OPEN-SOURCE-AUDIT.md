# V0.3.2 — Audit open source

Inspection des clones GitHub le 17 octobre 2026, avant conception. Lecture des README, licences et fichiers ci-dessous. Audit statique : les applications tierces et leurs suites ne sont pas annoncées comme exécutées. Aucun fichier de code tiers, données D&D, PDF, police ou illustration tierce n'est repris. Les modules existants Pilot20 offrent déjà les règles, choix, persistance et exports : leur réutilisation est plus sûre qu'une transplantation.

## Synthèse de valeur

Les fonctions permissives de navigation/JSON/calcul font doublon avec les fonctions déjà testées de Pilot20. Aucune transplantation n'accélère ce périmètre sans introduire un second état ou des règles divergentes. La réutilisation concrète porte sur le moteur, le créateur et le cache Pilot20, et sur les assets autorisés RPG Connect. Les nouvelles vues sont natives. Les principes généraux observés ci-dessus sont mis en œuvre sans copie de code tiers. Les exports PDF, PNG, modèles tiers et données 5etools ne sont pas intégrés.
