## Reproduce

`npm ci`, `npm test`, `npm run coverage:check`, `npm run coverage:catalog:check`, `npm run build:web`, `npx playwright install chromium`, `npm run test:e2e`.

`npm run dev` serves the packaged app locally. For a preinstalled Chromium, set `PILOT20_CHROMIUM` to its executable for E2E. The test starts and stops its own local server; no deployment is performed. Install/cache must complete online before offline use. Service-worker versions hash asset contents to avoid stale same-size releases.

Final local record: **352/352 Node tests passed**, coverage gates passed, engine/character/combat/catalogue/progression demos passed; **14/14 browser scenarios passed**, zero page errors. After refining template preferences, the 12 creator tests and all 14 browser scenarios were repeated successfully. Remote CI state is reported separately on the PR.
